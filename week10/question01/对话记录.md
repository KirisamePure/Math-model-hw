## 第一轮

### 用户（请求及附件摘要，非逐字转录）

在第 3 问中将人的体力下降因素考虑进去，模型会有什么改变？相对于不考虑体力下降的原模型，结果会如何？原模型为后两张图片。

附四张课件截图：

1. 横渡长江背景：1934 年武汉首次横渡长江竞赛；2002 年 5 月 1 日江水平均流速 1.89 m/s，186 人中仅 34 人到达终点，第一名成绩 14 分 8 秒，大部分人被冲到下游；起点武昌汉阳门，终点汉阳南岸嘴，江宽 1160 m，终点在下游 1000 m。
2. 问题（3）：流速沿离岸距离分布为 v(y) = 1.47 m/s（0 ≤ y ≤ 200）、2.11 m/s（200 < y < 960）、1.47 m/s（960 ≤ y ≤ 1160），游泳者速度 1.5 m/s 全程不变，选择游泳方向和路线并估计成绩。
3. 原模型：min T = Σ hᵢ/(u cos αᵢ)，约束 Σ hᵢ(vᵢ − u sin αᵢ)/(u cos αᵢ) = L；引入拉格朗日乘子 λ，令 ∂F/∂αᵢ = 0。
4. 问题（3）的简化：由 ∂F/∂αᵢ = 0 得 1/sin αᵢ − vᵢ/u = c；流速对中线对称 ⇒ 路线对中线对称 ⇒ 求解半程问题，h₁ = 200，h₂ = 380，L = 500，v₁ = 1.47，v₂ = 2.11，u = 1.5，求 α₁、α₂ 使 T = t₁ + t₂ 最小。

### AI（解题答复）

考虑体力下降后，模型主要变在三处：游速 u 不再是常数；“路线对中线对称、只算半程”的简化不再成立；最优条件要换成更一般的形式。下面先讲模型怎么改，再给数值结果和对比。

## 一、模型的改变

**1. 游速 u 变成变量**

原模型里 u 恒为 1.5 m/s。体力下降可以用两种方式描述：

- 按时间衰减，例如 u(t) = u₀ × e^(−kt) 或 u(t) = u₀ × (1 − βt)；
- 按横渡进度衰减，记为 u(y)。

游泳者的 y 随时间单调增加，所以可以近似把 u 写成 y 的函数。这样在第 i 个分层里取一个常数 uᵢ，就还能沿用课件中拉格朗日乘子的框架。

**2. 对称性被破坏，必须算全程**

原来能只算半程，是因为流速对中线对称，游速也处处相同。现在后半程游速更慢，两岸的路线不再对称，所以要把全程至少分成 3 层（0–200、200–960、960–1160），并且 L 取 1000 m，而不是半程的 500 m。要算得更细，可以把全程切成 n 条薄层，让 uᵢ 逐层递减。

**3. 最优条件推广**

目标函数是

```text
min T = Σ hᵢ / (uᵢ cos αᵢ)，
s.t.  Σ hᵢ(vᵢ − uᵢ sin αᵢ) / (uᵢ cos αᵢ) = L。
```

对 F 求偏导并令其为零：

```text
∂F/∂αᵢ = hᵢ[sin αᵢ + λ(vᵢ sin αᵢ − uᵢ)] / (uᵢ cos² αᵢ) = 0
⟹  uᵢ / sin αᵢ − vᵢ = C，  i = 1, 2, …, n。
```

当 uᵢ 都等于 u 时，这个式子就退化成原模型的 1/sin αᵢ − vᵢ/u = c。也就是说，原模型是这个新模型的特例。求解时只需对常数 C 做一维求根，使总漂移等于 L。

**4. 如果按时间衰减建模，情况更复杂**

u 取决于到达该层的时刻，而这个时刻又取决于前面各层的角度，各层之间就耦合起来了。上面的条件只是近似，严格做法要用最优控制（Pontryagin 极大值原理），或者对全部 αᵢ 直接做数值优化。

**5. 新出现的可行性问题**

一旦 uᵢ 小于该层水速 vᵢ（例如后段 u < 1.47），游泳者在这一层无论朝哪个方向游，都只能被冲向下游。所以必须在体力好的时候提前多往上游游一段，把这段余量留给后面。

## 三、与原模型相比

1. **成绩变差，而且越来越快地变差。** 终点游速只降 3%（到 1.45）时，用时增加约 5%；降 10%（到 1.35）时，用时增加约 23%。原因是后段游速接近甚至低于水速后，逆流能力急剧下降。
2. **路线不再对称。** 最优路线是“前段多偏向上游、后段少偏一些”：趁体力好先在上游留出余量，后面体力差时顺水漂到终点。每个区域内角度也不是常数，而是随体力连续变化。
3. **原模型的角度不再适用。** 体力下降后还按原角度游，会被冲到终点下游几十米，到不了终点。这正对应材料里“大部分人被冲到下游，未能到达终点”的现象。所以原模型的方案偏乐观，考虑体力后应当更早、更大幅度地向上游偏。
4. **前提不变。** 两个模型都假设游泳者能精确保持方向、水流只沿 x 方向；体力模型多出的衰减参数（k 或终点游速）需要根据实测数据来确定。
